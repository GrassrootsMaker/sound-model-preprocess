# Spresense (Sony CXD5602)

Sound classification example for **Sound Model Studio** lives in the Spresense SDK:

```
../../spresense/examples/sound_classify/
```

It compiles sources from this repository (`features/` + `pipeline/`) and loads
the TFLite model exported from Sound Model Studio.

See `../../spresense/examples/sound_classify/README.txt` for build and flash steps.
